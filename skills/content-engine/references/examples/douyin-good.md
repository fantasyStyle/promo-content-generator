# 抖音优秀脚本样本

## 样本一：剧情演绎风 — 工具/SaaS类

**为什么好：**
- 前3秒有情绪冲突（皱眉叹气+具体数字），立刻勾住注意力
- 用"之前vs之后"对比结构，转折清晰
- 产品出现的时机刚好（中间转折点），不是一上来就推
- 有具体场景演示（外卖/衣服/咖啡），不是光说
- 结尾号召口语化
- 口播每句话不超过15字，说出来顺

**原文（脱敏）：**
```
[0-3s] 人物对着手机皱眉："又花了300块…这个月还没过半呢…"
[3-8s] 手机屏幕特写，支出数字："记账记了两年，每次都只告诉我花了多少，越记越焦虑"
[8-15s] 人物换了一个小程序，表情从皱眉变惊喜："直到朋友推了我一个不一样的小程序——它不记花了多少，记省了多少！"
[15-25s] 快速演示：输入→自动算出省钱→数字上涨："比如买平替省300、用优惠券省17、自己做饭省25——每记一笔首页数字就涨，看着超爽"
[25-35s] 滑动展示各页面："还能看省钱日历、分类统计、学省钱小妙招、去社区看别人怎么省——记账第一次变成上瘾的事"
[35-40s] 人物面对镜头笑："一个月下来省了两千多。不是抠，是会过日子。小程序搜[产品名]，去试试"
```

**可复用结构：**
```
[0-3s 痛点场景+情绪] → [3-8s 问题放大] → [8-15s 产品出现+转折] → [15-25s 功能演示+具体数字] → [25-35s 效果展示] → [35-40s 号召+产品名]
```

**BGM建议：** 前段低沉→中间转折变轻快

## 样本二：口播讲解风 — 认知/知识类

**为什么好：**
- 开头用数据（90%）制造认知冲击，让人停下来看
- 不是直接讲产品，而是先分析"为什么你会失败"，建立信服力
- "同一个行为，完全不同的心理体验"这句话是核心记忆点
- 有真实使用数据增加可信度
- 结尾引导互动而非硬推销

**原文（脱敏）：**
```
[0-3s] 博主面对镜头："你知道吗？90%的人记账坚持不了一个月的真正原因，不是懒——是反馈机制搞反了"
[3-12s] 配合文字动画："传统记账给你的反馈是'你又花钱了'，这是负反馈。负反馈的事，人能坚持多久？但是有款工具把逻辑完全倒过来——它记的是你省了多少"
[12-25s] 小程序录屏："同样买一双鞋，传统记账：-299。这款工具：原价799你299入手，省了500块。你看到的是'省了500'，不是'花了299'——同一个行为，完全不同的心理体验"
[25-35s] 展示数据页："我用了3周，记账完成率从40%涨到90%，实际省了800多。因为你会主动寻找省钱机会来'喂'给这个工具——消费行为真的在改变"
[35-40s] 博主面对镜头："如果你试过记账没坚持下来，试试这个。小程序搜[产品名]。你怎么省钱的？评论区分享"
```

**可复用结构：**
```
[0-3s 数据/认知冲击开头] → [3-12s 分析问题本质 讲原理] → [12-25s 产品作为解决方案 有具体对比] → [25-35s 使用数据证明] → [35-40s 总结+互动引导]
```

**BGM建议：** 中等节奏知识型，平稳有力

## 样本三：痛点直击风 — 生活服务类

**为什么好：**
- 开头用具体数字（等了2小时）制造焦虑感，即刻共鸣
- 问题→放大→方案→效果，节奏紧凑
- 没有废话，40秒讲完一个完整故事
- 适合有明确使用场景的产品

**原文（脱敏）：**
```
[0-3s] 人物坐在地上，旁边是漏水的水管："家里水管漏了，打了4个电话——一个没空、一个天价、一个修不了、一个让我等3小时"
[3-10s] 人物抱头崩溃："那一刻真的想把房子卖了"
[10-20s] 人物拿出手机操作："直到朋友推了一个上门维修小程序——下单、选时间、报价透明。30分钟师傅就到了"
[20-30s] 展示师傅维修过程+前后对比+账单明细："上门费+维修费明码标价，修完还拍了对比照。从那之后，我家所有的维修都用这个"
[30-35s] 人物对着镜头比👍："住老小区、租老房子的，收藏一下，说不定什么时候就用上了"
```

**可复用结构：**
```
[0-3s 痛点场景+情绪] → [3-10s 问题放大] → [10-20s 解决方案+使用过程] → [20-30s 效果证明] → [30-35s 号召+适用人群]
```

## 样本四：场景代入风 — 社交/社区类

**为什么好：**
- 用"假如"开头把用户带入场景，参与感强
- 不直接说"这是读书社区"，而是展示加入后生活怎么变了
- 有真人案例感（王姐的故事）
- 情绪递进自然：无聊→好奇→上瘾→生活变了

**原文（脱敏）：**
```
[0-3s] 博主面对镜头，手机显示读书群界面："假如你每天通勤1小时，一年就能听完50本书。但为什么大多数人做不到？"
[3-10s] 快速切换群聊/书评/打卡界面："因为读书最难的不是读，是坚持。一个人读，读到第三页就困了。但有一群人一起，就不一样"
[10-20s] 展示社区功能：书评、读书笔记、群打卡、线下读书会照片"这个读书社区，有人读完一本书写了3000字笔记、有人每天通勤打卡听了200本书、同城还能约线下读书会"
[20-30s] 人物出镜+屏幕展示："我们群的王姐，退休教师，去年读了52本书写了10万字笔记。她说'一个人读是消遣，一群人读是成长'"
[30-35s] 结尾："如果你也想找到一起读书的人，小程序搜[产品名]。你最近在读什么书？"
```

**可复用结构：**
```
[0-3s "假如"场景代入+反问] → [3-10s 核心痛点分析] → [10-20s 社区功能展示+具体例子] → [20-30s 真实案例+金句] → [30-35s 号召+互动提问]
```

## 通用好脚本原则

1. **前3秒决定生死** — 必须有情绪冲击或认知冲突，不能平淡开场
2. **一句话不超过15字** — 口播要读出来顺，写的时候就读一遍
3. **一个视频只讲一件事** — 不要贪多，把一个差异点讲透
4. **关键信息重复一次** — 产品名出现2次（中间一次、结尾一次）
5. **结尾一定引导互动** — 提问、投票、评论区话题，平台算法看重互动率
6. **文字贴纸补充** — 静音用户占30%，关键信息要叠字
