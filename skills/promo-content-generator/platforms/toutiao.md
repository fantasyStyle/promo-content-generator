# 今日头条运营知识

## 平台特征

- **DAU**: ~1.5亿+
- **用户画像**: 30-55岁为主，男性略多，下沉市场渗透深，三四线城市用户占比高
- **内容调性**: 新闻感、信息增量、短平快、接地气
- **核心逻辑**: 纯推荐算法驱动，标题和首段决定推荐量，点击率+读完率是关键
- **内容形式**: 图文（短图文+长图文）、微头条（类似微博）、视频、问答
- **特点**: 图文内容的标题权重极高，决定 90% 的流量；文章审核较严

## 内容调性

像记者在报道一个有价值的发现。强调"信息增量"——读者读完要觉得"长了见识""学到了东西"。忌讳纯广告、无信息量的吹捧、过于文艺的表达。

**关键词感**：信息冲击 → 建立兴趣 → 展开说明 → 产品价值 → 互动引导

**语气参考**：
- 直接、有力、不绕弯子
- 像新闻标题一样精炼有冲击力
- 接地气，不要太精致太文艺
- 提供可量化的信息和具体的数据
- 篇幅在 500-1200 字为宜

## 标题公式

头条标题是决定生死的一环。标题不好，内容再好也没人看。

### 公式一：数字 + 结果
> "用了这个记账小程序，每月多存下2000元"
>
> 要点：数字要具体，结果要诱人

### 公式二：争议性提问
> "为什么大部分团长用的开团工具都在拖后腿？"
>
> 要点：制造认知冲突，引发点击看答案

### 公式三：信息差展示
> "做了2年知识付费，才知道分销裂变可以自动化"
>
> 要点：暗示读者"你可能也不知道"，激发求知欲

### 公式四：人群标签 + 利益承诺
> "家里东西坏了先别扔：上门维修比你想的便宜一半"
>
> 要点：精准命中目标人群+明确利益

### 公式五：避坑/防雷型
> "读书社群最怕的5个坑，第三个90%的群主都踩过"
>
> 要点：负面信息天然吸引点击，但要兑现内容

**标题原则**：
- 18-25 字以内
- 必须有信息增量感
- 慎用感叹号（1个最多了，多了像推销）
- 标注"广告""推广"如果文章是纯广告（头条审核要求）

**标题党红线（避免被封）**：
- 不要用"震惊""紧急通知""刚刚"
- 不要承诺文章内没有的内容
- 不要捏造数据或事实
- 不要在标题使用"最全""大全"等绝对化表述

## 正文结构

```
[开头] 1-2 段
  - 第一句直击核心（不要铺垫，头条用户没耐心）
  - 快速建立"这篇文章值得看"的感觉
  ↓
[核心信息] 2-3 段
  - 把最重要的信息放在前面（倒金字塔结构）
  - 是什么、为什么、怎么做到的
  ↓
[产品价值] 2-3 段
  - 产品如何解决具体问题
  - 用数据、对比、场景来说明
  ↓
[延伸价值] 1-2 段（可选）
  - 这个产品/方法对行业的启示
  - 提升文章的信息密度和收藏价值
  ↓
[结尾] 1 段
  - 一句话总结
  - 引导互动（"你怎么看？欢迎评论区讨论"）
```

## 封面图策略

### 三图模式
头条信息流中三图展示面积更大，点击率往往高于单图。
- 三张图有逻辑关系（如：问题→方案→结果）
- 每张图独立也有信息量
- 尺寸：每张 1:1 或 16:9，三张保持一致

### 单图模式
- 适合深度长文、观点类文章
- 封面图要传达文章主题的核心信息
- 尺寸：建议 16:9

### 封面图选择优先级
1. 产品截图 + 大字核心利益点（最推荐，信息量最直接）
2. 场景图 + 文字标题
3. 纯产品/品牌图（最不推荐，缺少信息量）

## 两种风格变体

### 风格A：信息增量风（理性向）

**特点**：像一篇行业分析或实用指南，信息密度高
**适合场景**：工具类、效率类产品，面向决策者和理性用户
**结构**：
```
[开头] 一个数据/现象引起注意
[正文] 分析现在的问题 → 介绍更好的方案 → 具体操作步骤
[结尾] 总结 + 互动
```
**标题示例**："个人记账工具的下半场：从记流水账到AI财务规划，这3个功能成标配"

### 风格B：故事叙述风（感性向）

**特点**：用一个人/一个故事带出产品，更接地气
**适合场景**：有真实案例的产品，面向普通用户
**结构**：
```
[开头] 一个人物的真实经历/变化
[正文] 从故事切入问题 → 方案如何改变了现状 → 扩展价值
[结尾] 情感升华 + 互动
```
**标题示例**："北京独居女生的一次上门维修经历，改变了她对'修东西'的认知"

## 运营贴士

- **最佳发布时间**：
  - 工作日 7:00-8:00（早间资讯阅读高峰）
  - 12:00-13:00（午休碎片阅读）
  - 18:00-20:00（晚间阅读高峰，流量最大）
  - 建议首推选择 **7:00-8:00** 或 **18:00-19:00**
- **推荐算法偏好**：
  - 前 100 字的点击率和读完率最重要
  - 用户收藏+分享的权重高于点赞
  - 文章标签和分类选择准确（发布时选对分类）
  - **新增（2025）**：头条对"标题党"的识别从关键词匹配升级为语义理解。"震惊""刚刚"等词不是唯一红线，过度夸张的语义本身也会被降权
- **微头条**：可以发一条 200 字以内的微头条做"预告"，加上文章链接（同一个号内），两条内容互相导流
- **评论区互动**：头条用户评论门槛低，评论量往往比其他平台多。保持评论区活跃，回复高质量评论，互动量会影响后续推荐
- **账号垂直度**：头条推荐一个账号的内容给用户时，会看这个账号"一直都发什么"。保持内容垂直，不要什么类型都发，否则推荐量下降
- **图文带货新规**：头条图文内容如果包含产品推广，需要在发布时勾选"包含商品推广"标签。未标注的推广内容可能被限流。纯软文（不说产品名、只提供价值）不受此限制。
- **微头条流量红利**：2025年微头条的推荐流量有明显增加。建议每篇长文配发一条100-200字的微头条做"预告+金句"，能有效导流。
