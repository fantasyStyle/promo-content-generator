# 多平台推广文案生成器

[![Version](https://img.shields.io/badge/version-v1.1.0-green)](https://github.com/fantasyStyle/promo-content-generator)

Claude Code 技能 — 读取小程序/App 项目信息，自动生成小红书、抖音、微信公众号、今日头条的推广文案。面向没有运营经验的产品经理和开发者。

## 覆盖平台

| 平台 | 产出 |
|------|------|
| 小红书 | 3-5 个标题备选 + 种草正文 + 话题标签（四分类）+ 配图清单 + 生图 prompt |
| 抖音 | 分镜脚本 + 口播稿 + BGM 建议 + 文字贴纸策略 + 视频封面 prompt |
| 微信公众号 | 5 个标题备选 + 深度长文 + 排版指南 + 引导话术 + 封面 prompt |
| 今日头条 | 3-5 个标题备选 + 信息流正文 + 封面图策略 + 标题党红线提醒 |

每个平台产出 **2 种风格变体** + 运营小贴士（最佳发布时间、互动技巧、避坑提醒）。

## 特性

- **7 步工作流** — 信息收集 → 产品分析 → 传播点提炼 → **产品类型识别** → 平台确认 → 生成文案 → 自检优化
- **5 种产品类型适配** — 自动识别工具/SaaS、电商、社交、内容、生活服务，匹配最佳推广策略和风格
- **文案质量标准** — 内建去模板感、去营销黑话检查，确保文案像真人写的
- **2 种风格变体** — 每平台 2 种风格，覆盖感性和理性受众
- **运营知识内嵌** — 最佳发布时间、互动技巧、限流词避坑、2025 算法变化
- **迭代修改** — 支持局部修改（"标题再夸张一点""语气换专业风格"）

## 使用

安装后，在 Claude Code 对话中直接说：

- "帮我生成推广文案"
- "分析我的小程序，出小红书和抖音的推广内容"
- "/promo 分析 ~/my-miniapp 这个项目"

技能会自动触发，按 7 步流程引导你：

1. **收集信息** — 读取项目代码/README，询问产品功能、目标用户、差异化卖点
2. **分析产品** — 总结产品定位，确认理解是否准确
3. **提炼传播点** — 一句话核心卖点 + 3 个支撑角度
4. **产品类型识别** — 自动判断产品类型（工具/电商/社交/内容/生活服务），匹配最佳策略
5. **确认平台** — 默认四平台全出，可指定部分
6. **生成文案** — 每平台 2 种风格，带配图建议和运营贴士
7. **自检优化** — 自动检查示例替换、产品名称、事实一致性、模板感

生成后可以说"标题再夸张一点""语气换更专业的"做局部修改。

## 示例

假设你有一个省钱记账小程序，对话大致如下：

```
用户: 分析我的小程序，项目在 ~/savings-app，帮我生成推广文案

Claude: [读取 README、pages.json、PRD 文档]
        了解了。你的产品是一个省钱记账小程序。
        请补充：核心功能是什么？目标用户是谁？

用户: 记录省钱金额、省钱统计、省钱社区、省钱小妙招。用户是20-35岁年轻人，想省钱但记账难坚持。

Claude: ## 产品分析（请确认）
        **产品定位**：个人省钱行为记录工具 + 省钱心得分享社区
        **核心功能**：省钱记账、省钱统计、省钱社区、省钱小妙招
        **目标用户**：20-35岁打工人，追求性价比
        **差异化**：传统记账告诉你"花了多少"，这个告诉你"省了多少"
        
        以上准确吗？

用户: 准确

Claude: ## 核心传播点
        **一句话卖点**：不记花了多少，只记省了多少
        **产品类型**：工具/SaaS → 推荐重点做公众号和头条，风格侧重理性分析
        
        要生成哪几个平台？

用户: 全出

Claude: ==== 小红书 ====
        ## 风格A：闺蜜安利风
        ### 标题
        1. 记账3年，我终于找到一款越记越开心的小程序
        2. 不是记账！是记"省了多少钱"，用了之后我真的省了好多
        ...
        [完整文案 + 标签 + 配图建议 + AI生图prompt]
        
        ==== 抖音 ====
        ...
        ==== 微信公众号 ====
        ...
        ==== 今日头条 ====
        ...
```

## 设计哲学

- **真实优先** — 所有文案基于实际产品信息，不编造功能
- **平台适配** — 同一核心信息，不同平台用不同的"人话"讲
- **产品类型自适应** — 自动识别产品类型，匹配最佳推广策略
- **去模板感** — 像真人写的，不是换产品名的万能句式
- **运营经验内嵌** — 发布时间、互动话术、限流词避坑、算法趋势
- **迭代友好** — 支持局部修改，不改整体
