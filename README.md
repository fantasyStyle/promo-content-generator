# 多平台推广文案生成器

Claude Code 技能 — 读取小程序/App 项目信息，自动生成小红书、抖音、微信公众号、今日头条的推广文案。面向没有运营经验的产品经理和开发者。

## 覆盖平台

| 平台 | 产出 |
|------|------|
| 小红书 | 3-5 个标题备选 + 种草正文 + 话题标签（四分类）+ 配图清单 + 生图 prompt |
| 抖音 | 分镜脚本 + 口播稿 + BGM 建议 + 文字贴纸策略 + 视频封面 prompt |
| 微信公众号 | 5 个标题备选 + 深度长文 + 排版指南 + 引导话术 + 封面 prompt |
| 今日头条 | 3-5 个标题备选 + 信息流正文 + 封面图策略 + 标题党红线提醒 |

每个平台产出 **2 种风格变体** + 运营小贴士（最佳发布时间、互动技巧、避坑提醒）。

## 安装

### 方式一：一键安装（推荐）

```bash
gh skill install fantasyStyle/promo-content-generator
```

### 方式二：从 GitHub 手动安装

```bash
git clone https://github.com/fantasyStyle/promo-content-generator.git
cd promo-content-generator
ln -sf "$(pwd)/skills/promo-content-generator" ~/.claude/skills/promo-content-generator
```

### 方式三：手动复制

```bash
cp -r skills/promo-content-generator ~/.claude/skills/promo-content-generator
```

## 使用

安装后，在 Claude Code 对话中直接说：

- "帮我生成推广文案"
- "分析我的小程序，出小红书和抖音的推广内容"
- "/promo 分析 ~/my-miniapp 这个项目"

技能会自动触发，按 5 步流程引导你：

1. **收集信息** — 读取项目代码/README，询问产品功能、目标用户、差异化卖点
2. **分析产品** — 总结产品定位，确认理解是否准确
3. **提炼传播点** — 一句话核心卖点 + 3 个支撑角度，确保四平台信息一致
4. **确认平台** — 默认四平台全出，可指定部分
5. **生成文案** — 每平台 2 种风格，带配图建议和运营贴士

生成后可以说"标题再夸张一点""语气换更专业的"做局部修改。

## 示例

假设你有一个社区团购小程序，对话大致如下：

```
用户: 分析我的小程序，项目在 ~/group-buy-app，帮我生成推广文案

Claude: [读取 README、app.json、主要页面]
        了解了。你的产品是一个社区团购团长管理工具。
        请补充：核心功能是什么？目标用户是谁？

用户: 一键开团、自动分账、提现秒到账。用户是小区的宝妈团长，想赚零花钱。

Claude: [输出产品分析，用户确认]
        
        ## 核心传播点
        **一句话卖点**：社区团长提现最快、最省心的开团工具
        
        要生成哪几个平台？

用户: 小红书和公众号

Claude: 
        ==== 小红书 ====
        ## 风格A：闺蜜安利风
        ### 标题
        1. 做团购3个月，终于找到提现秒到账的开团工具了
        2. 小区宝妈看过来！用对工具每天多睡2小时
        ...
        [完整文案 + 标签 + 配图建议 + AI生图prompt]
        
        ==== 微信公众号 ====
        ...
```

## 设计哲学

- **真实优先** — 所有文案基于实际产品信息，不编造功能
- **平台适配** — 同一核心信息，不同平台用不同的"人话"
- **运营经验内嵌** — 发布时间建议、互动话术、避坑提醒已内置于技能中
- **迭代友好** — 支持局部修改，不改整体
