# 多平台推广文案生成器 — 设计文档

## 目标

为没有产品运营经验的人员，构建一个 Claude Code Skill，读取小程序/App 项目信息和截图后，自动生成具有资深运营水准的多平台推广文案。

## 覆盖平台

- 小红书（种草风格）
- 抖音（短视频脚本）
- 微信公众号（深度长文）
- 今日头条（信息流风格）

## 文件结构

```
.claude/skills/promo-content-generator/
├── skill.md                    ← 主 Skill，管整体流程
└── platforms/
    ├── xiaohongshu.md          ← 小红书运营知识
    ├── douyin.md               ← 抖音运营知识
    ├── wechat.md               ← 公众号运营知识
    └── toutiao.md              ← 头条运营知识
```

## 主流程

1. **收集信息** — 读项目代码/README（如有本地路径）、询问产品功能/目标用户/差异化卖点、接收截图、确认推广目标
2. **分析产品** — 总结产品定位、提炼核心卖点、描述目标人群画像
3. **提炼核心传播点** — 一句话核心卖点 + 3 个支撑角度（功能/情感/场景）+ 目标人群画像，确保四平台信息一致
4. **确认平台** — 默认四平台全生成，可按需指定
5. **按平台规则生成** — 加载对应平台配置，按调性和模板生成，每平台 2 种风格变体
6. **输出** — 按平台分段输出文案 + 配图描述/生图提示词 + 运营贴士

### 交互特性

- 支持迭代修改：用户可指定修改某部分（如"标题更夸张"），只改对应内容
- 同产品二次生成时跳过信息收集，直接选平台
- 支持拖入截图
- 接受风格指令（更年轻化/更专业/更幽默等）

## 各平台产出规格

### 小红书

- 3-5 个标题备选（数字+痛点+解决方案、悬念式、结果展示式）
- 正文（个人体验引入→痛点共鸣→产品解决方案→使用效果→行动号召）
- 话题标签（行业词、场景词、人群词、长尾词四类）
- 配图清单（每张图内容+角度，首图特别说明）
- 生图提示词（AI 生成封面/场景图的 prompt）
- 2 种风格变体：闺蜜安利风 + 干货测评风
- 运营贴士（发布时间、评论区互动话术、敏感词避坑）

### 抖音

- 视频脚本分镜表（镜号+画面描述+口播文案+时长，黄金3秒开头）
- 发布文案（标题+话题标签）
- BGM 建议（推荐音乐类型/情绪）
- 文字贴纸建议
- 生图提示词（视频封面图）
- 2 种风格变体：剧情演绎风 + 口播讲解风
- 运营贴士（发布时间、dou+投放建议、评论区引导）

### 微信公众号

- 5 个备选标题（悬念式、数字式、对比式、痛点式）
- 正文（开头引入→问题分析→解决方案→产品介绍→使用场景→结尾引导关注）
- 排版建议（段落长度、小标题节奏、配图插入点）
- 封面图描述 + 生图 prompt
- 引导关注/转发/社群引流话术
- 2 种风格变体：情感共鸣风 + 理性分析风
- 运营贴士（推送时间、朋友圈转发文案、社群分发建议）

### 今日头条

- 3-5 个备选标题（数字+结果、争议提问、信息差展示）
- 正文（快速切入→核心信息→产品价值→互动引导）
- 封面图策略（三图/单图） + 生图 prompt
- 2 种风格变体：信息增量风 + 故事叙述风
- 运营贴士（推荐算法偏好、标题党红线、发布时间）
